# Premier lancement client

L'application client demande toujours une connexion dès l'ouverture. Le numéro et
le code permettent d'identifier le compte avant d'afficher les commandes et la
conversation. Un nouveau client indique ensuite son nom, utilisé pour la
livraison. Un client déjà connecté arrive directement sur l'accueil après la
vérification de son profil.

Ces étapes utilisent un fond clair continu, une typographie sobre et des champs
sans bordure. Il n'y a ni grand panneau de marque ni écran de présentation
supplémentaire. Le logo et les photos de produits restent dans les contenus où
ils sont utiles, pas dans le formulaire.

L'autorisation de notifications n'est pas demandée à la connexion : elle est
sollicitée après une commande réussie ou au retour sur une commande en cours,
quand le suivi a un sens. La localisation est demandée uniquement si le client
choisit sa position pour la
livraison ; le micro et l'appareil photo restent déclenchés par leurs actions.
